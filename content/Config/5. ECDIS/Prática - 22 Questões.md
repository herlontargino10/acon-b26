## Configuração do ECDIS

### 1. Modo de exibição

-  Selecione o modo de exibição do display como **Custom**.
    
    - `Task list / Chart / display category`
        

### 2. Camadas da carta

-  Selecione as camadas para apresentação na carta, pelo menos:
    
    - **Spot sounding to 15m**
        
    - **Name**
        
    - **Other Information**
        
    - `Tasks list / Chart / Layer`
        

### 3. Sensor primário de posição

-  Qual o sensor primário de posição?
    
    - `Painel de controle`
        

### 4. Criar e monitorar rota

-  Crie uma rota com **5 WPT**.
    
-  Monitore:
    
    - **CRS**
        
    - **XTD**
        
    - **BTW**
        
    - **DTW**
        
    - etc.
        
- `Botão multi-tarefas / Route data`
    

### 5. Ativar sensores disponíveis

-  Ative todos os sensores disponíveis:
    
    - **DGPS 1**
        
    - **Gyro 1**
        
    - **Dlog 1**
        
    - **Echosounder 1**
        
- `Tasks list / Navigation`
    

### 6. Habilitar sensores

-  Habilite os sensores:
    
    - **AIS**
        
    - **ARPA A**
        
    - **ARPA B**
        
- `Painel de controle`
    

### 7. Habilitar alvos

-  Habilite os alvos:
    
    - **Targets**
        
    - **Show Targets**
        
    - **ARPA A B**
        
    - **AIS Tracks**
        
- `Task list / Targets`

## Monitoramento da navegação

### 8. Monitorar a área

-  Monitore a área visualmente.
    
- Observe os **alvos habilitados acima**.
    

### 9. Monitorar o navio

-  Monitore o navio.
    
-  Habilite:
    
    - **Headline**
        
    - **COG vector**
        
    - **HDG vector**
        
- `Tasks list / Monitoring / Route monitoring`
    

### 10. Exibição do navio e vento

-  Habilite para exibir o navio como **contorno**, e não como símbolo.
    
-  Habilite o **Wind vector**.
    
- `Tasks list / Monitoring / Route monitoring`
    

### 11. Alinhamento do contorno

-  Habilite para alinhar o **contorno do navio ao HDG vector**.
    
- `Tasks list / Monitoring / Route monitoring`
    

### 12. Monitorar alarmes

-  Monitore os alarmes durante a navegação:
    
    - **Safety Contour**
        
    - **Safety Depth**
        
- `Tasks list / Monitoring / Safety alarms / Safety parameters`
    

### 13. Configurar vetor do navio

-  Configure o **vetor do navio**.
    
- `Painel de controle / ... / min`
    

### 14. Alterar fuso horário

-  Altere o fuso horário do navio para **3W**.
    
- `Tasks list / Config / Tab Time zone`
    

### 15. Exibir hora do navio

-  Altere para o ECDIS exibir a **hora do navio**.
    
- `Painel de controle – clique no relógio`

## AIS e mensagens

### 16. AIS no Conning

-  Ligue o **AIS no Conning**.
    
- `Botão UP / Nav. Aids`
    

### 17. AIS no display da carta

-  Acione o **AIS no display da carta**.
    
- `Painel de Controle`
    

### 18. Mensagem de segurança

- `Tasks list / AIS / messaging`
    

### 19. Mensagem normal

- `Tasks list / AIS / messaging`

## Navegação e planejamento

### 20. Orientação do comandante

> [!warning] Instrução do comandante  
> Você recebeu a orientação do comandante para chamá-lo na entrada do canal.

-  Insira essa informação na **carta**.
    

### 21. Preencher o Schedule

-  Preencha o **Schedule** considerando:
    
    - Velocidade do navio: **10 nós**
        
    - Saída no **WP0**: **1200Z**
        
    - Fuso horário: **3W**
        
    - Dentro do canal: velocidade máxima de **4 nós**
        
-  Determine **a hora de chegada ao último WP**.
    

### 22. Maré — Porto de Seattle

-  Determine **qual a altura da maré no porto de Seattle (US)** quando o navio estiver no **último WP**.
    
-  Verifique se o porto **possui facilidades**.
