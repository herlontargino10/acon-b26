# 2ª QUESTÃO — VERDADEIRO OU FALSO

## 2.1
Metacentro = encontro dos raios da curva descrita pelo centro de carena.
→ **V**

## 2.2
KG é distância entre G e K.
→ **V**

## 2.3
Centro de empuxo = centro de gravidade.
→ **F**

## 2.4
BM define sozinho estabilidade.
→ **F**

## 2.5
KG obtido pelo teorema de Varignon.
→ **V**

## 2.6
KB e KM não podem ser obtidos na tabela hidrostática.
→ **F**

## 2.7
GZ é distância vertical.
→ **F**

## 2.8
Navio que retorna está em equilíbrio indiferente.
→ **F**

## 2.9
BM·senθ representa estabilidade de formas.
→ **V**

## 2.10
Para reduzir superfície livre usa anteparas transversais.
→ **F**

# RESUMO FINAL

GM > 0 → Estável

GM = 0 → Indiferente

GM < 0 → Instável


GZ = GM × senθ

Me = Δ × GZ

KM = KB + BM
