# 1. Onde a Estática entra na Mecânica

Mecânica responde duas perguntas:

### 1) O corpo está em equilíbrio?

→ ESTÁTICA

### 2) O corpo está se movendo?

→ CINEMÁTICA / DINÂMICA

---

## Exemplo no navio

Situações típicas de Estática:

- carga suspensa pelo guindaste;
    
- âncora parada no cabo;
    
- escada de portaló sustentada;
    
- container apoiado.
    

Pergunta sempre:

**As forças estão equilibradas?**

---

# 2. Conceito de Equilíbrio

Equilíbrio significa:

A soma de todas as forças atuando no corpo é igual a zero.

Física:

ΣF = 0

Consequência:

a = 0

Sem aceleração.

---

## Exemplo

Peso:  
500 N ↓

Tração:  
500 N ↑

Resultado:

500 − 500 = 0

Equilíbrio.

---

# 3. Força — O que realmente significa

Força é:

Uma interação entre corpos.

Toda força possui:

- módulo → intensidade;
    
- direção → linha de atuação;
    
- sentido → para onde atua.
    

---

## Exemplo naval

Vento → força

Corrente → força

Cabo → força

Peso → força

---

# 4. Partícula × Corpo Rígido

## PARTÍCULA

Modelo simplificado.

O objeto é tratado como:

→ um ponto com massa.

Ignora:

- forma;
    
- rotação;
    
- deformação.
    

Importa apenas:

- posição;
    
- velocidade;
    
- aceleração.
    

---

### Exemplo

Navio visto muito longe.

Você ignora dimensões.

Só acompanha posição.

---

## CORPO RÍGIDO

Modelo mais completo.

Considera:

- tamanho;
    
- geometria;
    
- rotação.
    

Assume:

- não deforma.
    

---

### Exemplo

Leme do navio.

Importa:

- eixo;
    
- rotação;
    
- momento.
    

---

# 5. O que significa "não deformar"

Corpo rígido:

As distâncias internas permanecem constantes.

Se puxar:

→ não estica.

Se comprimir:

→ não encurta.

Se torcer:

→ não retorce.

Só muda:

- posição;
    
- orientação.
    

---

## Analogia

Como se todos os pontos internos estivessem soldados.

# 6. Erro clássico

ERRADO:

Partícula = pequeno

Corpo rígido = grande

CERTO:

Depende do problema.

Exemplos:

Terra orbitando Sol:  
→ partícula

Giroscópio:  
→ corpo rígido

# 7. Como identificar questões

## Palavras de Partícula

- aceleração
    
- velocidade
    
- trajetória
    
- centro de massa
    

Normalmente:

→ forças apenas

---

## Palavras de Corpo Rígido

- barra
    
- escada
    
- torque
    
- momento
    
- eixo
    
- rotação
    
- guindaste
    

Normalmente:

→ forças + rotação

# 10. Exemplo Resolvido

Uma carga de 1000 N está suspensa.

Pergunta:

Qual a tração?

---

Forças:

Peso = 1000 N ↓

Tração = T ↑

Equilíbrio:

T − 1000 = 0

Resposta:

T = 1000 N

---

Interpretação:

O cabo sustenta exatamente o peso.

---

# 11. Erros Mais Comuns

Erro 1

Confundir massa e peso.

Massa → kg

Peso → N

---

Erro 2

Olhar só intensidade.

Esquecer direção.

---

Erro 3

Achar que equilíbrio significa parado.

Pode mover com velocidade constante.

---

Erro 4

Escolher fórmula antes de entender.
