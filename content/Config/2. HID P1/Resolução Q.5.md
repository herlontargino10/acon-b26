## Passo 6 — Determinar os expoentes

Como Π₁ é adimensional:

[L][ML⁻³]ᵃ[ML⁻¹T⁻¹]ᵇ[LT⁻¹]ᶜ = 1

Igualando a zero os expoentes de M, L e T:

- M: a + b = 0
    
- L: 1 − 3a − b + c = 0
    
- T: −b − c = 0
    

Resolvendo o sistema:

a = 1; b = −1; c = 1

Substituindo em Π₁ = Dρᵃμᵇuᶜ:

**Π₁ = Re = ρuD/μ**
